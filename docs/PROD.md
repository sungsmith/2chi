# PRD: 이취 (2chi)

## 목표

취준생이 이력을 STAR 구조로 한 번 정리하면, 자소서·경력기술서·포트폴리오·면접 준비까지 AI가 자동으로 뽑아주는 취업 올인원 도구.

---

## 사용자

| 세그먼트 | 설명 |
|----------|------|
| 신입 취준생 | 첫 취업 준비. 이력이 적고, 자소서 작성 경험 없음. 어떻게 써야 하는지 모름. |
| 중고신입 (경력 1~5년) | 이직 준비. 경력은 있지만 매번 새 회사에 맞게 자소서·경력기술서 재작성이 번거로움. |

**공통 페인포인트**:
- 공고마다 자소서를 처음부터 다시 씀
- 자소서·경력기술서·포트폴리오에 비슷한 내용을 각기 다른 형식으로 반복 정리
- 지원한 회사·단계·결과를 어디에 정리해야 할지 모름
- 면접 준비를 체계적으로 못 함

---

## 핵심 기능

### Phase 1 — MVP

1. **인증** — 회원가입 / 로그인 / 토큰 갱신
2. **내 이력 관리 (STAR)** — 경험을 Situation·Task·Action·Result 구조로 입력·편집. 역량 태그 자동 추천. AI로 자유서술 → STAR 변환.
3. **자소서 작성** — 채용공고 입력 → AI가 이력 기반 초안 생성 (SSE 스트리밍) → 편집 → AI 피드백 (점수, 어색한 표현, 키워드 누락).
4. **지원 현황 + 캘린더** — 지원 상태 트래킹 (서류 → 1차 → 최종 → 합격/불합격), 마감일·면접 일정 캘린더.

### Phase 2

5. **경력기술서** — AI 초안 생성 + 섹션 편집 + PDF 다운로드
6. **기업·직무 분석** — 채용공고 분석 → 필요 역량 추출 → 내 이력과 매칭도 시각화
7. **채용공고 URL 스크랩** — URL 붙여넣기 → 자동 파싱 → JobPosting 저장
8. **온보딩 PDF 파싱** — 기존 이력서 PDF 업로드 → AI 구조화 → 이력 자동 등록

### Phase 3

9. **포트폴리오** — 이력 기반 포트폴리오 생성 + PDF 다운로드
10. **면접 준비** — 공고 기반 예상 질문 생성 + 사용자 답변 + AI 피드백
11. **이력 프로필** — 지원 목적별 이력 선별 묶음 (마케팅용, 기획용 등)
12. **지원 패턴 분석** — 합격률, 단계별 통과율 통계

## 외부 서비스 수동 설정

### Cloudflare R2 (Phase 2부터 필요, 자동 세팅 불가)

R2는 파일 업로드(이력서 PDF/Word, 생성 PDF)에 사용한다. 아래 단계를 직접 수행해야 한다:

1. [Cloudflare 대시보드](https://dash.cloudflare.com) → R2 Object Storage → 버킷 생성
2. **버킷명** → `.env`의 `R2_BUCKET_NAME`에 입력
3. **계정 ID** → 대시보드 우측 하단 → `R2_ACCOUNT_ID`에 입력
4. R2 → 계정 개요 → "API 토큰 관리" → 토큰 생성 (권한: Object Read & Write)
   - Access Key ID → `R2_ACCESS_KEY_ID`
   - Secret Access Key → `R2_SECRET_ACCESS_KEY`
5. 버킷 → 설정 → 퍼블릭 액세스: **비활성화** (Signed URL 방식 사용)

## 디자인 방향

- **컨셉**: 매일 쓰는 도구. 마케팅 페이지 아님.
- **모드**: 라이트 모드 기본 (긴 글 읽기·작성에 최적)
- **컬러**: 뉴트럴 베이스 + 블루 포인트 (신뢰감, 전문성)
- **톤**: 군더더기 없이 깔끔. 기능이 앞에 나오고 장식은 뒤로.
- 자세한 디자인 시스템은 `docs/UI_GUIDE.md` 참조.
