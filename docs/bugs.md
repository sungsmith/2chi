# 버그 트래커

버그 발견 시 여기에 기록하고, 수정 완료 시 상태를 업데이트한다.

## 형식
```
### BUG-NNN: 제목
- **발견일**: YYYY-MM-DD
- **상태**: 발견 | 수정 중 | 완료
- **원인**: 원인 설명
- **수정**: 수정 방법
```

## 완료된 버그

### BUG-001: 자소서 항목 추가 동작 안 함
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: `createCoverLetterItemSchema`에서 `order` 필드가 필수(Int)인데 폼에 입력 없음 → Zod 유효성 실패
- **수정**: 폼 제출 시 기존 items 수를 `order`로 자동 부여

### BUG-002: 기업분석 결과보기 버튼 반응 없음
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: 이미 `/company` 페이지에 있는데 `router.push('/company')` 해서 변화 없음
- **수정**: 버튼 제거, 큐 등록 후 목록 섹션으로 스크롤 + refetch

### BUG-003: 캘린더 안 뜸 (그리드 UI 없음)
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: CalendarView가 월별 그리드 없이 목록만 렌더링
- **수정**: 7열 월간 그리드 캘린더로 재구현, 날짜 셀에 이벤트 표시

### BUG-004: 보드와 캘린더 연동 안 됨
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: 보드(applications)와 캘린더(calendarEvents)가 별개 데이터. 지원의 deadline이 캘린더에 안 뜸
- **수정**: CalendarView에서 applications 데이터도 함께 조회, deadline을 캘린더 이벤트로 표시

### BUG-005: 이력 수정 시 시작일/종료일 안 채워짐
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: `<input type="date">`는 `YYYY-MM-DD` 형식 필요한데 ISO 문자열 그대로 전달
- **수정**: `.slice(0, 10)`으로 변환 후 defaultValues에 주입

### BUG-006: 이력 목록 날짜 ISO 포맷 그대로 노출
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: `2022-04-01T00:00:00.000Z` 원본 문자열 그대로 렌더링
- **수정**: `iso.slice(0, 10)`으로 표시

### BUG-007: 자소서 삭제 후 목록 즉시 반영 안 됨
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: `invalidateQueries`만 있고 즉시 refetch 없음
- **수정**: `refetchQueries` 추가

### BUG-008: 기업분석에 무의미한 입력(초성/랜덤)도 처리됨
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: 입력값 검증 없이 GPT에 바로 전달, GPT가 허구 내용 생성
- **수정**: 프롬프트에 유효하지 않은 기업명 감지 규칙 추가, BadRequestException 반환

### BUG-009: `/company/undefined` 라우팅
- **발견일**: 2026-04-19
- **상태**: 완료
- **원인**: 기업분석 API가 비동기(jobId) 반환 시 company.id 없어서 undefined
- **수정**: cached/queued 응답 분기 처리

### BUG-010: 세션 만료 후 자동 갱신/리다이렉트 없음
- **발견일**: 2026-04-20
- **상태**: 완료
- **원인**: api.ts에서 401 응답 처리 없음
- **수정**: 401 시 refresh token으로 재발급 시도, 실패 시 /login 리다이렉트
